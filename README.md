# Notes Only

Read, rehearse and copy speaker notes privately.

Open the page, then drop in a Word document (.docx), a text file or a PowerPoint (.pptx), or paste your notes. Notes are split into parts at each heading, with a practice mode (big text, timer, keyboard and swipe controls).

Everything is read inside your browser. Files are never uploaded anywhere.

## Privacy and security

- Nothing is uploaded: files are read by the page inside your own browser.
- A strict Content Security Policy blocks the page from contacting any server (no fetch, images, forms, beacons or websockets), so notes cannot leave the device.
- Only the page's own hash-pinned code can run; injected scripts and `eval` are refused.
- No cookies, analytics, trackers or third-party code. Referrers are not sent.
- The page hides itself if another site tries to embed it.
- Notes are remembered only in your own browser on this device; use **Remove** to clear them.
